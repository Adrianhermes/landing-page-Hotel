# Publicacao Estatica

Esta pasta contem a versao estatica da landing page para deploy em GitHub Pages ou Vercel.

## GitHub Pages
1. Envie o repositorio para o GitHub.
2. Em `Settings > Pages`, selecione:
   - Branch: `main` (ou a branch principal)
   - Folder: `/docs`
3. Salve e aguarde a URL publica.

## Vercel
1. Importe este repositorio na Vercel.
2. O arquivo `vercel.json` ja redireciona tudo para `/docs`.
3. Clique em Deploy.

## Observacoes
- Esta versao e somente demonstracao (sem backend PHP/MySQL).
- O formulario de reserva e as acoes de "saiba mais" funcionam em modo demo no front-end.
